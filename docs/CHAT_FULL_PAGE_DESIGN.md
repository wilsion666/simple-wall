# 整页聊天界面设计文档

## 1. 页面结构

### 布局说明
整页聊天界面采用三层垂直布局，参考 ChatGPT 主界面：

```
┌─────────────────────────────────────────┐
│ Header (标题 + 模型选择 + 操作按钮)      │ ← 固定顶部
├─────────────────────────────────────────┤
│                                         │
│  Messages Container (消息列表，可滚动)  │ ← 自适应高度
│                                         │
│                                         │
├─────────────────────────────────────────┤
│ Input Bar (输入框 + 发送按钮)            │ ← 固定底部
└─────────────────────────────────────────┘
```

### 组件层级
- **Body** (100vh，全屏高度)
  - **Header** (顶部栏，flex-shrink: 0)
    - 左侧：标题 "与AI对话" + 模型选择下拉框
    - 右侧：清空记录按钮 + 返回首页链接
  - **Messages Container** (中间区域，flex: 1，可滚动)
    - **Messages** (消息列表)
      - 初始状态：居中显示 "我们从哪里开始呢？"
      - 用户消息 (右对齐，灰色背景)
      - AI消息 (左对齐，白色背景，显示 via {model})
  - **Input Container** (底部栏，flex-shrink: 0)
    - 输入框 + 发送按钮
    - 错误提示区域

## 2. 布局容器代码

### 全屏高度支持
```css
body {
  height: 100vh;        /* 全屏高度 */
  overflow: hidden;     /* 防止页面滚动 */
  display: flex;
  flex-direction: column;
}

.chat-header {
  flex-shrink: 0;       /* 固定高度，不收缩 */
}

.chat-messages-container {
  flex: 1;              /* 占据剩余空间 */
  overflow-y: auto;     /* 内容超出时滚动 */
}

.chat-input-container {
  flex-shrink: 0;       /* 固定高度，不收缩 */
}
```

### 宽度自适应
- **不设置 max-width**：页面宽度自适应屏幕宽度
- **消息内容**：使用 `max-width: 100%` 防止溢出
- **输入框容器**：使用 `max-width: 100%` 自适应

## 3. 关键特性

### 初始状态
- **居中显示**：使用 flexbox 居中
- **文案**："我们从哪里开始呢？"
- **样式**：灰色文字 (#999)，18px 字体

### 模型选择
- **位置**：Header 左侧，标题旁边
- **选项**：GPT-5.2 / Gemini 3 / Claude / DeepSeek R1
- **默认值**：GPT-5.2
- **禁用规则**：生成中不可切换

### AI消息 via 标签
- **显示位置**：消息内容下方
- **格式**：`via {model}`
- **样式**：
  - 标签文字：灰色 (#999)
  - 模型名称：蓝色 (#0066cc)，加粗
  - 字体大小：12px

### 输入框固定底部
- **实现方式**：使用 flexbox，`flex-shrink: 0`
- **始终可见**：无论消息列表多长，输入框始终在底部
- **背景**：白色，顶部边框分隔

## 5. 功能保持

### 切换模型影响范围
- **只影响后续消息**：切换模型后，已发送的消息保持不变
- **不清空历史**：切换模型时不再询问是否清空对话
- **新消息使用新模型**：切换后的消息使用新选择的模型

### API调用
- **端点**：`/api/chat-mock`
- **请求格式**：
  ```json
  {
    "messages": [...],
    "model": "gpt-5.2"
  }
  ```
- **响应**：流式 SSE 格式

### 消息显示
- **用户消息**：右对齐，深色背景 (#111)
- **AI消息**：左对齐，白色背景
- **via 标签**：每条AI消息下方显示 `via {model}`

## 6. 样式特点

### 设计风格
- **参考 ChatGPT**：
  - 全屏布局，无宽度限制
  - 简洁的顶部栏
  - 居中的初始状态
  - 固定在底部的输入框

### 颜色方案
- **背景**：#fff (页面和消息)
- **用户消息背景**：#f7f7f7 (消息容器), #111 (消息气泡)
- **文字**：#111 (主要), #333 (次要), #999 (提示)
- **强调**：#0066cc (链接/聚焦/via标签)
- **错误**：#c00 (错误文字), #fee (错误背景)

### 间距
- **消息间距**：24px (桌面), 16px (移动端)
- **消息内边距**：16px 20px (桌面), 12px 16px (移动端)
- **输入框内边距**：16px 24px (桌面), 12px 16px (移动端)

### 响应式
- **桌面端**：宽松间距，大字体
- **移动端**：紧凑间距，小字体
- **输入框**：自适应高度（最大200px）

## 8. 技术实现

### 布局技术
- **Flexbox**：实现垂直布局和自适应高度
- **固定定位**：Header 和 Input Bar 使用 `flex-shrink: 0`
- **滚动容器**：Messages Container 使用 `overflow-y: auto`

### 状态管理
- `currentModel`: 当前选择的模型
- `isGenerating`: 是否正在生成回复
- `messages`: 消息历史数组（包含 model 字段）

### 流式响应处理
- 使用 Server-Sent Events (SSE)
- 逐字符更新消息内容
- 实时显示 via 标签
